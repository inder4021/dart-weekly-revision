## 🚀 How to Run

1. Install Dart SDK.
2. Clone this repository.
3. Open the project folder in VS Code.
4. Open any `.dart` file.
5. Run the program using:

```bash
dart run program_01_student_result.dart
```

Replace the filename with the program you want to execute.
